• 학교 검색 → 조회 범위 설정 → 중식 불러오기 → 식단 다듬기 순서로 작업하세요.
🏫 1. 학교 검색
API 키는 화면에 노출하지 않고 Vercel 환경변수 NEIS_API_KEY에서 서버가 읽습니다.
📅 2. 조회 범위 설정
조회 범위와 날짜를 먼저 정하면, 이후 불러오는 식단과 예시 카드가 함께 바뀝니다.
현재 자료 구성: 하루 게시자료
🍱 3. 선택 기간 중식 불러오기
✏️ 4. 식단 다듬기
나이스에서 불러온 식단을 그대로 사용하거나, 게시 목적에 맞게 제목·부제·핵심 메뉴·안내 문구를 수정하세요.
입력 방법: 원문 => 바꿀 문구 형식은 수정, => 없이 입력하면 해당 단어/문구를 삭제합니다.
🖼️ 디자인 프리셋
탭을 누르면 조회 범위도 함께 바뀌고, 카테고리를 누르면 해당 스타일 카드만 표시됩니다.
